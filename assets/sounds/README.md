# Sleep Alarm Sounds

This directory contains alarm sound files for the Sleep Tracker feature.

## Required Files

You need to add the following MP3 files to this directory:

- `sunrise.mp3` - A gentle sunrise-themed alarm sound
- `forest.mp3` - Forest ambient sounds (birds chirping, nature)
- `ocean.mp3` - Ocean waves sound
- `birds.mp3` - Bird chirping sounds
- `chimes.mp3` - Gentle chimes or bells sound

## Sound Requirements

- Format: MP3
- Duration: 15-30 seconds (will loop if alarm continues)
- Volume: Normalized to consistent levels
- Style: Gentle, gradual increase in volume recommended

## Free Sound Resources

You can find free alarm sounds at:
- freesound.org
- zapsplat.com
- mixkit.co
- YouTube Audio Library (convert to MP3)

Make sure any sounds you use have proper licensing for your use case.
